# ☀️ Weather Dashboard

A clean, responsive web application that displays real-time weather information for any city using live REST APIs and persistent browser storage.

---

## 🚀 Features

* **Real-time Weather Data:** Fetches temperature, wind speed, wind direction, and coordinates asynchronously using `async/await`.
* **Recent Search History:** Saves recently searched cities locally using `localStorage` for quick access.
* **Responsive Dark Interface:** Styled with modern CSS layout techniques (Flexbox/Grid) featuring dark mode and glassmorphism styling.
* **Dynamic DOM Updates:** Smooth UI changes driven by modern JavaScript (ES6+).

---

## 🛠️ Tech Stack & Requirements Met

* **Core Stack:** HTML5 (semantic structure), CSS3 (Flexbox/Grid, mobile responsiveness), JavaScript ES6+.
* **APIs & Storage:** Open-source REST API integration (`async/await`) and browser `localStorage`.
* **Version Control:** Git version control hosted on GitHub.
* **Live Deployment:** Deployed via GitHub Pages.
